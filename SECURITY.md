# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue, pull request or discussion for security problems.

Report vulnerabilities privately through GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/vapor47/slop-or-not/security) of this repository.
2. Click **Report a vulnerability** (or open the [advisory form](https://github.com/vapor47/slop-or-not/security/advisories/new) directly).
3. Describe the issue, the affected endpoint or file, steps to reproduce, and the impact you expect.

Only the maintainer can see the report. You will get an acknowledgement as soon as practical, and we will
coordinate a fix and disclosure with you through the advisory. Please give us a reasonable amount of time to
release a fix before disclosing the issue publicly.

## Scope

This is a small hobby project. The supported version is whatever is currently on the `main` branch; there are
no maintained release branches.

Please do not run automated scanners, denial-of-service tests or social-engineering attempts against any
deployed instance, and do not access or modify data that is not yours.
